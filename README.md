## 📖 About the project

<p style="text-align: justify;">
The objective of this assignment was to create a simple number guessing game using C#. The user is given a limited number of attempts to guess a randomly generated number. The application must meet the following requirements:
<ul>
  <li>The game generates a random number that the user needs to guess.</li> 
  <li>The user can enter a guess through the console.</li>
  <li>The user receives a hint if the guess is too high or too low.</li>
  <li>The user has a limited number of attempts to guess the correct number.</li>
  <li>The game informs the user when they successfully guess the correct number.</li>
  <li>The game informs the user when all attempts have been used without finding the correct number.</li>
  <li>At least one part of the game logic is implemented using a separate method.</li>
</ul>
</p>

In addition to the basic requirements, the project includes the suggested extra challenges. The user can choose a difficulty level, receive varied responses, get hints based on how close their guess is to the correct number, and restart the game without restarting the application.

## ✨ Features

### **Number guessing game**
The user is asked to guess a randomly generated number. The game provides feedback after each guess, indicating whether the guessed number is too high or too low.

### **Difficulty levels**
The user can choose between different difficulty levels. Each level changes the range of numbers that can be generated and the number of attempts available.

### **Varied responses**
To make the game more engaging, the responses are varied instead of displaying the same message after every guess. The game still clearly communicates whether the guess was too high or too low.

### **"It's getting hot!" hints**
The game provides additional feedback based on how close the user's guess is to the correct number. Guesses that are close to the correct number receive a different response than guesses that are far away.

### **Restart the game**
After finishing a game, the user can choose whether to play again. This allows the game to restart without having to close and run the application again.

### **Win and lose conditions**
The game displays a congratulatory message when the user guesses the correct number. If all available attempts are used without guessing correctly, the game displays a message informing the user that they were unsuccessful.
